# Windows 正式版使用与验证

当前正式版为 `3.0.1`。用户已反馈在 Windows + VRChat 实际使用正常；以下步骤供首次使用、升级及环境差异检查。无需安装 Python。

1. 下载 `VRChatDanceAssistant-windows-x64.zip`，将整个 `VRChatDanceAssistant` 文件夹解压到当前账户可写的独立目录（中文路径也可以）。
2. 保留 `VRChatDanceAssistant.exe` 旁的 `_internal` 等全部文件，不能只复制 exe；也不要把 exe 重命名为中文（SteamVR 客户端库无法用中文进程名写日志，VR 面板会报 NoLogPath）。升级前备份旧 `config.json`、`mapping.json` 和视频目录，在独立目录解压新包；确认旧相对路径后再迁入配置，不覆盖或合并 `_internal`。
3. 双击 `VRChatDanceAssistant.exe`，按 UAC 提示启动；此入口会自动启动真实缓存服务。程序未签名，发布者显示为未知。
4. 在“存储／设置”填写实际目录和所需选项并应用。修改保存目录、YouTube 缓存开关前先停止服务，应用后重新启动；等待活动任务结束再改目录。
5. 打开 VRChat 的 PyPyDance 房间，检查队列识别、CDN/YouTube 视频请求、缓存命中与后台保存。不要与其他接管相同域名的缓存工具同时运行。
6. 正常关闭程序，检查服务退出和 hosts 恢复。有恢复失败提示时保留窗口，按提示重试并保留日志。

正式版默认浅蓝布局，不再附带“小余12主题”和背景。旧个人主题及导入图片保留；若旧背景只有程序资源副本，将显示主题底色，可在外观页重新导入。演示保存的外观与正式模式分开。

`docs/build-info.json` 记录此包的实际源码提交、Windows 隔离测试及冻结 exe 演示检查。它们不代表真实 VRChat、hosts 恢复、旧曲库兼容或 Windows 缩放已人工验收。

遇到问题请记录：页面与操作步骤、服务状态、错误提示、相关日志，以及是否使用旧配置/曲库。可从界面复制或导出运行日志。

## 验证跟随 SteamVR 启动

1. 将完整程序目录放在固定位置，正常打开助手并启动 SteamVR。
2. 在“设置 → 启动”点击“刷新状态”，勾选“跟随 SteamVR 启动”后点击“应用启动设置”，等待成功提示。
3. 退出助手，重启 SteamVR，确认**没有任何** Windows 管理员授权提示，助手自动打开且服务启动（自启走最高权限计划任务，全程无 UAC）。
4. 保持助手运行再重启 SteamVR，确认不会出现第二个助手进程（单实例锁唤醒已有窗口）。
5. 在助手中取消勾选并应用，退出助手并重启 SteamVR，确认助手不再自动启动；同时在“任务计划程序”中确认 `VRChatDanceAssistant-SteamVR` 任务已被删除。
6. 用含中文、空格的安装路径重复检查；移动程序目录后重新打开助手，确认状态页提示启动路径已自动更新，无需重开开关。

SteamVR 关闭不会退出助手。演示模式只预览开关交互，不执行注册。自动化隔离测试和 DLL 加载检查不代表上述实机步骤已通过。

## 默认 CoolDown 视频

2.0.1 随包提供默认视频（原片 5,073,920 字节、约 3 分 16 秒，无音视频重新编码）。CoolDown 路径留空时使用内置视频，已有自选视频继续使用；需要切回默认时，在“设置”中点击“使用内置视频”并应用更改。随后在“运行”页手动启用 CoolDown，等待后续视频请求触发替换。首次使用此版本时请在 VRChat 中确认默认视频实际播放正常。
